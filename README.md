# Rihab Tourism App

A Flutter mobile application for exploring tourism destinations and attractions through a structured, multi-screen experience.

## Features
- Tourism categories and destination browsing
- Splash screen and multi-screen navigation
- Structured destination models
- External map links for locations
- Reusable Flutter screens and widgets

## Tech Stack
- Flutter & Dart
- Material UI
- `url_launcher`

## Project Structure
```text
lib/
├── main.dart
├── models/
│   └── monument.dart
└── screens/
    ├── splash_screen.dart
    ├── main_page.dart
    └── category_page.dart
```

## Getting Started
```bash
flutter pub get
flutter run
```

## Status
Academic / portfolio project.

## Notes
The project focuses on Flutter navigation, data modeling, UI composition, and linking destination information to external maps.
